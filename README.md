# schoen-portfolio
Personal portfolio page for Tenure Teaching Portfolio

## Local Images + GitHub Pages Deploy

Place your images in `public/images/`.

Vite copies everything in `public/` into the production build (`dist/`), and your `npm run deploy` command publishes `dist/` to GitHub Pages. That means images in `public/images/` are automatically included in the live site.

This project now expects these image files:

- `public/images/cv-card.jpg`
- `public/images/curriculum-development-card.jpg`
- `public/images/beyond-the-classroom-card.jpg`
- `public/images/letters-of-support-card.jpg`
- `public/images/etec-150.jpg`
- `public/images/etec-141.jpg`
- `public/images/etec-140.jpg`
- `public/images/etec-139.jpg`
- `public/images/etec-138.jpg`
- `public/images/etec-137.jpg`
- `public/images/etec-136.jpg`
- `public/images/etec-135.jpg`
- `public/images/etec-134.jpg`

Deploy as usual:

```bash
npm run deploy
```
